# Visual Principles (Working Draft)

## Purpose

Treat visual form as a way to expose structure and status, not as decoration alone.

## Working principles

- Preserve conceptual hierarchy in visual hierarchy.
- Encode status with labels and shape as well as color.
- Keep provenance and validation state visible beside a claim.
- Use restrained color; the existing SOVRINT Visual Bible identifies deep navy, observability cyan, restrained gold, white, and optional ivory as palette roles.
- Optimize for legibility on small screens and in print.
- Record source, version, and author for every exported visual.

## Evaluation questions

Can a reader identify the system boundary, component, state, evidence class, and source without inferring them from color alone?

This draft is not a validated usability standard.
